# LAU Byblos: real reference photos

All of these come from LAU's own pages for the **Byblos** campus. Each building page is under
`fm.lau.edu.lb/physical-facilities/buildings-grounds/buildings/byblos/` (the Byblos list: 19 buildings), so they are Byblos by
construction, not guessed from a picture. I found nothing from social media or Google Images that I could attribute to Byblos with
certainty (the search tool returns pages, not pictures), so none is used.

The photo servers only answer with a browser User-Agent and a Referer from the same site; the files are
`https://fm.lau.edu.lb/images/<name>NN.jpg` (NN = 01 to 10). Building pages: `…/byblos/<page>.php`.
